# Reading list

Start from official kernel documentation. Add a one-line note when a page was useful.

- Kernel docs home: https://docs.kernel.org/
- Current HTML docs: https://www.kernel.org/doc/html/latest/
- How the kernel tree is developed: https://www.kernel.org/doc/html/latest/process/development-process.html
- Coding style: https://www.kernel.org/doc/html/latest/process/coding-style.html
- Out-of-tree modules: https://www.kernel.org/doc/html/latest/kbuild/modules.html
- Kernel build system: https://www.kernel.org/doc/html/latest/kbuild/index.html
- Submitting patches (for later, if you ever send a real fix): https://www.kernel.org/doc/html/latest/process/submitting-patches.html

Subsystem indexes worth skimming once the hello module builds:

- Memory management: https://www.kernel.org/doc/html/latest/mm/index.html
- Networking: https://www.kernel.org/doc/html/latest/networking/index.html
- Scheduler: https://www.kernel.org/doc/html/latest/scheduler/index.html

Public vulnerability summaries, when you write them, link the advisory and the fixing commit. They stay in `docs/` and follow `CVE_STUDY_TEMPLATE.md`.
